```powershell
powershell -ExecutionPolicy Bypass -File scripts/test-databases.ps1
powershell -ExecutionPolicy Bypass -File scripts/prepare-stack-databases.ps1
```

## 三、启动真实后端（推荐 FastAPI + PostgreSQL）

```powershell
cd backend/python-fastapi
$env:APP_PORT='8080'
$env:DB_DRIVER='postgres'
$env:DATABASE_URL='postgres://postgres:postgres@localhost:55432/orange_fastapi'
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8080
```

自检：

```powershell
Invoke-WebRequest http://localhost:8080/api/v1/health -UseBasicParsing
```

注意：必须 `cd backend/python-fastapi` 后再用 `.venv\Scripts\python.exe`；
直接在仓库根写相对路径会被 PowerShell 当成模块名。

其他后端也可替换，启动方式见各栈 README；数据库连接串见 `docs/DB-MATRIX.md`。


Vue：

```powershell

$env:VITE_MOCK_ENABLE='false'

```
