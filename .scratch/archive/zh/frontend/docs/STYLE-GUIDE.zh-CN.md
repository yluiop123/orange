# 视觉一致性指南

React 是基准。Angular 和 Vue 要让人一眼看出是同一个产品：主色、间距节奏、表面、字体和外壳尺寸一致即可，不要求像素完全相同。

## 设计变量

| 变量 | 值 | 用途 |
| --- | --- | --- |
| 主色 | `#f97316`（orange 500） | 按钮、选中菜单、焦点环、链接 |
| 主色前景 | `#fff7ed` | 主色上的文字/图标 |
| 背景 | `#ffffff` / 暗色 `#18181b` | 页面 |
| 卡片 | `#ffffff` / 暗色 `#27272a` | 面板、弹窗、表格 |
| 前景 | `#18181b` / 暗色 `#fafafa` | 文字 |
| 次要文字 | `#71717a` | 辅助说明 |
| 弱表面 | `#f4f4f5` / 暗色 `#27272a` | 表头、悬停 |
| 边框 | `#e4e4e7` / 暗色 `#3f3f46` | 卡片、输入框、分隔线 |
| 危险色 | `#ef4444` | 删除、错误 |
| 圆角 | `0.65rem`（约 10px） | 卡片、按钮、输入框、弹窗 |
| 侧边栏宽度 | `16rem`（收起 `3rem`，移动端 `18rem`） | 外壳 |
| 顶栏高度 | `3rem` | 顶部栏 |
| 页面内边距 | `0.75rem` | 页面内容 |
| 内容间距 | `1rem` | 卡片/区块之间 |
| 字体 | 系统 UI 字体栈 | 全部文字 |

React/Tailwind 用 OKLCH；Angular Material 和 Vuetify 可直接用上面的十六进制值，视觉差异很小。

## 外壳

- 左侧侧边栏 16rem，浅色表面（暗色 `#18181b`），右侧 1px 边框。
- 顶部放品牌/Logo；菜单分组标题「菜单」；底部放用户信息。
- 顶栏 3rem：左侧标题/面包屑，右侧语言、主题、操作。
- 选中菜单：橙色浅底 + 主色文字；悬停：弱表面。
- 内容区：`0.75rem` 内边距，卡片间距 `1rem`。

## 组件

- 按钮：高 2rem，圆角 `0.65rem`；主按钮橙色，次按钮描边。
- 输入框/下拉：高 2rem，带边框，圆角 `0.65rem`；焦点环橙色。
- 卡片：白/暗表面，1px 边框，`0.65rem` 圆角，不用重阴影。
- 表格：表头弱表面，行分隔线 1px，行高 2.5rem，分页右对齐。
- 弹窗：`0.65rem` 圆角，标题 + 内容 + 底部操作，危险操作放右侧。
- 状态：启用绿色 `#22c55e`，停用弱色。
- 图表沿用各库默认，但第一条系列用橙色。

## 验收

1. 三个应用在 1440×900 下截同一页面（`/system/user`、`/dashboard/normal`）。
2. 主色、侧边栏宽度、顶栏高度、页面内边距、卡片圆角一致。
3. 不残留 Material/Vuetify 默认紫/蓝。
4. 暗色模式符合上面的变量。
5. 字体回退到系统栈，不因缺少网络字体产生布局跳动。
