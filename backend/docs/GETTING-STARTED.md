# Backend Getting Started

All stacks serve the same `/api/v1` contract and share one schema. Pick one
stack, load the schema, generate its local config, then run it. The per-stack
README is authoritative for toolchain details.

## 1. Load a database

From the repository root:

```bash
# PostgreSQL (default for the quick start)
psql -U postgres -c "CREATE DATABASE orange;"
psql -U postgres -d orange -f database/postgres/ddl.sql
psql -U postgres -d orange -f database/postgres/dml.sql

# MySQL / MariaDB
mysql -uroot -proot -e "CREATE DATABASE orange DEFAULT CHARACTER SET utf8mb4;"
mysql -uroot -proot orange < database/mysql/ddl.sql
mysql -uroot -proot orange < database/mysql/dml.sql
```

SQLite uses `database/sqlite/ddl.sql` and `dml.sql` with the engine's CLI. Schema
and seed are never generated by a backend at startup.

## 2. Configure the stack you chose

Each stack has its own committed example next to its code. Copy it once and edit
the local file:

```bash
cp backend/go-gin-gorm/.env.example backend/go-gin-gorm/.env.local
cp backend/node-nestjs/.env.example backend/node-nestjs/.env.local
cp backend/csharp/.env.example backend/csharp/.env.local
cp backend/rust-axum/.env.example backend/rust-axum/.env
cp backend/python-fastapi/.env.example backend/python-fastapi/.env
cp backend/springboot/src/main/resources/application-local.example.yaml \
   backend/springboot/src/main/resources/application-local.yaml
```

See [CONFIGURATION.md](./CONFIGURATION.md) for variable names, precedence and
database switching.

## 3. Run one stack

| Stack | Command | URL |
| --- | --- | --- |
| Spring Boot | `cd backend/springboot && SPRING_PROFILES_ACTIVE=local mvn spring-boot:run` | <http://localhost:8080> |
| Go | `cd backend/go-gin-gorm && go run ./cmd/server` | <http://localhost:8081> |
| C# | `cd backend/csharp && dotnet run --project src/Orange.Api` | <http://localhost:8082> |
| Rust | `cd backend/rust-axum && cargo run` | <http://localhost:8083> |
| NestJS | `cd backend/node-nestjs && pnpm install && pnpm start:dev` | <http://localhost:3000> |
| FastAPI | `cd backend/python-fastapi && uvicorn app.main:app --port 8000` | <http://localhost:8000> |

Seed accounts: `super/super`, `admin/admin`, `user/user`; `auditor` and `newbie`
cover the audit and forced-password-change flows.

## 4. Verify

```bash
# Per-stack unit tests
cd backend/springboot && mvn test
cd backend/go-gin-gorm && go test ./...
cd backend/csharp && dotnet test
cd backend/rust-axum && cargo test
cd backend/node-nestjs && pnpm test
cd backend/python-fastapi && pytest

# Live database matrix (PowerShell, from the repository root)
./scripts/test-databases.ps1
```

Frontend end-to-end suites in `scripts/e2e/real-*.mjs` expect the backend at
`http://127.0.0.1:8080` (Spring Boot) unless the generated config says otherwise.

## Notes

- The four SQLite/MySQL/MariaDB/PostgreSQL paths are the tested matrix.
  openGauss, OceanBase and GoldenDB ship static SQL only.
- Spring Boot is the behaviour reference; when another stack differs, compare
  against Spring Boot first.
- Never point a backend at a database whose schema was created by a different
  engine's DDL.
